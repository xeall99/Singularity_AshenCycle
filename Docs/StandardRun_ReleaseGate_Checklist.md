## Transaksi save dan reset

- **Continue:** menu Main Menu menampilkan Continue Stage 1/10 untuk checkpoint fresh run. File checkpoint kandidat ber-hash valid dan merekam seed `-1739614289`, depth 1/10, HP 100, Mana 5, Embers 0, tanpa modifier, active dan di map boundary. Ini mendukung reset fresh run; tutup/relaunch lalu memilih Continue untuk membuktikan restore state yang sama masih **NOT RUN**.
- **Recovery:** saat salinan save uji rusak/terpotong, periksa apakah backup valid dapat dipulihkan atau game menawarkan run bersih tanpa crash dan tanpa menerapkan modifier yang belum divalidasi. Pakai hanya salinan data uji; jangan merusak profil asli. **TOOL PASS** 1–2 Oktober pada AnomalyGlyph: primary terpotong, Recover memulihkan StateJson backup persis, termasuk modifier dan identitas.
- **Clear:** PASS pada sesi manual 13 November untuk empat hasil: History mencatat 4 run Clear, Top Runs memeringkat semuanya dengan score/depth/boss/durasi sesuai Summary. Setelah Run 4, checkpoint run baru di Main Menu telah lolos checksum dan memuat Base Stats (HP 100/Mana 5), Embers 0, dan 0 modifier; Echo total tetap 513. Continue menunjukkan run baru Stage 1/10, bukan run selesai.
- **Defeat:** kalah dalam combat normal; Summary/History mencatat hasil kalah sekali, checkpoint tidak bisa dilanjutkan, dan New Expedition tidak membawa modifier run kalah.
- **Abandon:** dari Main Menu pilih New Expedition saat save aktif. Cancel harus mempertahankan checkpoint; konfirmasi membuat identitas baru, depth awal, dan temporary build kosong. **TOOL PASS** 2 Oktober pada AnomalyGlyph dengan Vital Core aktif; hash checkpoint setelah Cancel sama persis dan konfirmasi mereset HP/Mana/Embers/modifier/statistik.
- **Save gagal / Retry:** dalam profil uji, periksa **PROGRESS NOT SAVED** dan **RETRY SAVE**. - **Koreksi skor:** hanya Event Horizon dan Reversal Orbit memberi +50, maksimal tiga bonus per battle yang selesai. Unstable Pulse tetap memberi efek/total statistik tanpa poin dan tanpa memakai cap. Model 1 tetap terbaca di History; Top Runs memakai model 2. - Main Menu kini tidak menyediakan akses player-facing ke Content Manager. Uji menu diperbarui untuk memastikan tombol/panel tidak tersedia; uji CRUD internal memasang `ContentManagerUI` hanya di dalam test. - Katalog 15 skill tetap draf kurasi developer; belum ada inventory, loadout, pilihan skill tiga kartu, passive runtime, atau reward tiap 10 wave. Nilai damage dan Mana belum menjadi balance final.
- Play Mode setelah pemisahan menu belum terverifikasi. Runner terhenti sebelum menghasilkan XML ketika Unity gagal mengakses file sementara/Library dan Licensing Client mengalami kegagalan IPC/time-out. Hasil ini **NOT RUN**, bukan PASS; hasil historis 151/151, 149/149, dan 144/144 tidak membuktikan perubahan menu ini.
- Status release gate di atas tidak berubah: laporan run sebelumnya tetap **USER-REPORTED PASS** tanpa metadata lengkap, dan penerimaan manusia untuk executable Windows setelah koreksi skor masih pending.
- Lanjutkan dengan memulihkan runner Unity, menghasilkan XML baru untuk perubahan menu, lalu menghubungkan penerimaan manusia ke executable yang tepat beserta hash, tanggal, resolusi, seed dan RunId.
